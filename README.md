## What is Dupr Tools?

Dupr Tools is a lightweight, browser-facing toolkit built around HTML and common repository chores. Developers can reach the workspace through a normal web page instead of installing a heavy desktop stack.

Because the project is static-site friendly, it drops cleanly onto hosts such as GitHub Pages and stays simple to refresh when a new release lands. Think of it as a quick-launch surface for repo support work rather than a full IDE.
